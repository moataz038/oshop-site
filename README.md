# Oshop (اوشوب) — موقع الوكيل الذكي

نسخة من تصميم موقع آفاق بنفس الهيكل بالضبط، مع تغيير الهوية فقط لشركة **اوشوب Oshop** (Shipping & E-commerce).

- الموقع: https://oshop-ly.vercel.app (مشروع Vercel: `oshop-ly`، وهو نفس مشروع آفاق القديم بعد تغيير اسمه؛ الرابط القديم afaaq-ly يحوّل تلقائيًا للجديد)
- إنستغرام: https://www.instagram.com/oshop.company
- فرع مصراتة: الدائري الثاني، تقاطع المقاوبة — واتساب 0927172021 — https://maps.app.goo.gl/XkrM5y7T1ahBsXFD7
- فرع طرابلس: الجرابة، قرب مطعم تقاسيم — واتساب 0947172021 — https://maps.app.goo.gl/s8fjUVYXkY1EDM6BA

## ما تغيّر
- الاسم: أفاق/آفاق ← اوشوب (الواجهة + تعليمات الوكيل الذكي في السيرفر + رسائل التفاوض للموردين).
- الألوان: الأزرق/البنفسجي ← برتقالي اوشوب `#F37022` و `#F7941D`، وخلفيات دافئة.
- الثيم الافتراضي `oshop`، ومفتاح الإعدادات `oshop_prefs`.
- الشعار الثلاثي الأبعاد: نفس محرك الرسم، بشكل شعار اوشوب (الحلقة + السهم) بلون برتقالي لامع.
- الشعار المسطح والأيقونة: `brand/`.
- صفحة الإعدادات: فرعي مصراتة وطرابلس (خرائط)، إنستغرام، واتساب لكل فرع.

## التركيز (تحديث 2)
- ألغينا قسم "موتورز" بالكامل (زر التبديل، اختيار القسم في الإعدادات، تعليمات الوكيل).
- الاقتراحات والاهتمامات صارت على: الأزياء النسائية، عطور البراندات المشهورة من السعودية، الملابس التركية المشهورة، البراندات العالمية، مستلزمات الأطفال، الشنط والأحذية، وشي إن.
- مقارنة الأسعار تبدأ من أمازون السعودية، ثم نون وأمازون الإمارات، ترينديول، أمازون أمريكا (بدون علي بابا).
- `tools/focus.py` يطبّق التحديث هذا بعد `tools/rebrand.py`.

## النشر
```
cp -r vercel-output <dir>/.vercel/output
cd <dir> && vercel link --project oshop-ly && vercel deploy --prebuilt --prod
```
مفاتيح `GEMINI_API_KEY` و `REEF_API_KEY` موجودة في المشروع، والوكيل الذكي شغال.

`tools/rebrand.py` هو السكربت اللي حوّل نسخة آفاق المنشورة إلى اوشوب.
